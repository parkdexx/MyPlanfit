질문해주신 내용(불확실한 부분)에 대한 답변
Q1. GCP 사용비용 외에는 무료로 움직이고 싶습니다. 무료로 개발할 수 있게 도와주세요.

A. 네, 클라우드 자원을 전략적으로 활용하면 100% 무료(또는 월 몇백원 수준)로 운영이 가능합니다.

GCP 무료 혜택(초 프리 티어): 구글 클라우드(GCP)는 특정 미국 리전(예: us-central1, us-west1 등)에서 e2-micro 인스턴스 1대와 매월 30GB의 일반 디스크를 평생 무료로 제공합니다. 즉, 이 서버 1대를 띄워두는 것은 비용이 들지 않습니다.
데이터베이스(MySQL) 비용 주의사항: 보통 생각하시는 클라우드 데이터베이스 서비스(GCP의 Cloud SQL)는 '상시 무료 티어'가 존재하지 않아 무조건 과금이 됩니다. 따라서 완전 무료를 원하신다면 방금 말씀드린 저 무료 e2-micro 1대 서버 안에 Node.js(백엔드), 프론트엔드 배포 코드를 비롯해 MySQL DB(Docker 등 활용)까지 몽땅 직접 다 설치해서 서비스 하나에 통째로 올리는 방식을 채택하시면 됩니다. 사용자가 수십~수백 명 규모가 되기 전까지는 이 1대의 마이크로 서버로도 충분히 돌아갑니다.
Q2. 클라우드에 비정상적으로 접근하여 과도한 요금을 (트래픽 등으로) 발생하게 하는 것을 원천 예방하고 싶습니다.

A. 서버 비용 폭탄을 방지하기 위해서는 로직적 방어와 인프라적 방어가 모두 들어가야 합니다.

백엔드 로직 방어 (Rate Limit API): 누군가 매크로나 새로고침 연타로 API를 호출하는 것을 막기 위해, Node.js 코드에 express-rate-limit 같은 라이브러리를 추가할 예정입니다. (예: "같은 1개의 IP에서는 1분에 최대 100회까지만 API 호출 허용, 그 이상은 차단")
CORS 엄격 설정: 우리가 만든 프론트엔드 도메인(URL)에서만 백엔드(API) 코드를 호출할 수 있도록 화이트리스트를 엄격하게 묶어버려서, 외부 악의적 스크립트가 접근하지 못하게 차단합니다.
Cloudflare 연동 (강력 추천): 서버 앞단에 무료 보안망인 Cloudflare 프록시를 씌워두는 것이 최고의 방법입니다. 봇, 디도스(DDoS) 공격, 악성 찌르기 등을 Cloudflare가 내 서버에 도달하기도 전에 무료로 대신 다 맞고 걸러주기 때문에, GCP 서버에 과도한 트래픽(아웃바운드 과금 요소) 자체가 발생하지 않습니다.
결제 예산 알림 액션 설정 (최후의 보루): 가장 마음 편한 조치로, GCP 자체의 "결제 예산" 메뉴에서 예산을 1,000원(혹은 1달러)으로 설정해 두고 결제 금액이 이 이상 오를 기미가 보이면 즉시 이메일과 알림이 오도록 "Billing Alerts"를 걸어둡니다.
위 내용들을 바탕으로, 언제든 개발 시작(Phase 0 세팅)을 원하시면 편하게 말씀해 주세요! 시작을 도와드리겠습니다.
